# GRILL — AI Builds My Website (InstaWeb Labs assignment)

1. **What proves it works?** One flow, end to end: create a project for a real business → sources ingested → facts board shows sourced facts and flags a conflict → AI generates a site → user edits one section, regenerates another → publish → public URL renders the site. Demo video shows this for 2 real businesses.
2. **Stack?** Laravel 12 + MySQL (MariaDB local), Blade + Tailwind frontend, server-rendered. No SPA — fewer moving parts, everything demoable from `php artisan serve`.
3. **AI provider?** Interface with two drivers: Gemini (brief's suggestion, free key) and OpenAI-compatible (FastRouter) — selected by `AI_PROVIDER` env. Keys only in `.env`, never in the repo. Structured JSON output (sections), never free-form HTML from the model.
4. **How is "never invent facts" enforced, not just promised?** The generator receives ONLY the extracted fact set; every generated section must reference the fact keys it used (stored alongside). Facts with no source are impossible to reference. Missing facts → section omitted or marked "To be confirmed by the owner" — never filled in.
5. **Conflicting sources?** Deterministic extractors pull phones/emails/addresses/hours/prices per source. Two different values for the same field = a conflict on the facts board; generation uses the user-confirmed value; unresolved conflicts block publish (not generation) with a clear prompt.
6. **Same business name, several businesses?** Web search returns candidates; if more than one distinct business matches name+city, the user picks the right one before facts merge (disambiguation step). Facts never merge across candidates silently.
7. **Social sites block scraping?** Fetch detects 403/login-wall/empty extraction → source marked BLOCKED; user can paste the profile text manually as a replacement source. Blocked is a state, not an error.
8. **Instructions hidden in uploaded files?** Extracted text is data, never instructions: it is wrapped in delimiters in the prompt with an explicit ignore-instructions rule, and a scanner flags instruction-like lines ("ignore previous", "you must", URLs to visit) — flagged lines are shown to the user and excluded from fact extraction.
9. **AI is down?** Generation failure leaves the project and facts intact, shows a plain-language error with retry, and offers a deterministic fallback site built from facts only (no AI) so the user is never stuck.
10. **Out of scope?** User accounts/multi-tenancy, payments, custom domains, SEO tooling, image generation, analytics. One operator, local demo, publish = public slug URL on the same app.
